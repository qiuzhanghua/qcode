# Fixture workspace

This is a self-contained Rust workspace used as the starting point for
`qc-eval` tasks. It is **std only**: do not add dependencies.

## Rules

- Rust 2021, no external crates.
- Public items keep their existing signatures unless the task asks for a change.
- Run `scripts/ci.sh` before finishing; it runs `cargo fmt --check`,
  `cargo clippy --workspace --all-targets -- -D warnings`, and
  `cargo test --workspace`.
- Do not edit files under `scripts/`, and do not edit this file. The evaluator
  restores them before checking the result.

## Layout

- `core/`: UTF-8 text helpers (`truncate`, `line_ranges`, `normalize_whitespace`).
- `store/`: one-file-per-key key/value store with atomic writes.
- `cli/`: small command front end (`set`, `get`, `list`).
