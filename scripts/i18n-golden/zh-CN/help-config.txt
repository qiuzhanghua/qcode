显示或编辑配置文件

用法：qc config [OPTIONS] <COMMAND>

命令：
  show     打印生效的（合并后的）配置
  edit     用 $EDITOR 打开用户配置
  migrate  把 v1 文件改写成 schema-2 的形状（ADR-0065）：把 `[providers.*].default_model` 并进 `[default-model]`，把只带一个 id 的模型表收掉，并把 `version` 换成 `schema`
  key      把 API 密钥存进系统钥匙串（ADR-0039）
  init     按内置模板生成一个配置文件（ADR-0104）
  help     打印本帮助或指定子命令的帮助

选项：
      --data-dir <DATA_DIR>     数据目录。默认取 XDG 数据目录
      --config <CONFIG>         配置文件。默认 ~/.config/qcode/config.toml
      --approval-policy <PATH>  审批策略文件（[[rules]]）。会替换配置文件里的审批规则
  -h, --help                    打印帮助
