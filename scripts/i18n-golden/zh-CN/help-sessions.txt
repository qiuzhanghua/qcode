查看已落盘的会话

用法：qc sessions [OPTIONS] <COMMAND>

命令：
  list         列出已存的会话，最新的在前
  show         把一个会话按 JSON 重放出来
  fork         把一段对话前缀复制成一个新会话
  gc           删掉最后一个事件早于 N 天的会话
  delete       按 id 删掉一个或多个会话
  checkpoints  列出一个会话记下的检查点（文件改动前的快照）
  rollback     把工作区退回到某一轮之前的状态
  help         打印本帮助或指定子命令的帮助

选项：
      --data-dir <DATA_DIR>     数据目录。默认取 XDG 数据目录
      --config <CONFIG>         配置文件。默认 ~/.config/qcode/config.toml
      --approval-policy <PATH>  审批策略文件（[[rules]]）。会替换配置文件里的审批规则
  -h, --help                    打印帮助
