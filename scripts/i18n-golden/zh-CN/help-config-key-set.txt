从 stdin 读密钥存进去，然后打印那行配置

用法：qc config key set [OPTIONS]

选项：
      --data-dir <DATA_DIR>     数据目录。默认取 XDG 数据目录
      --provider <PROVIDER>     配置里的供应商名，例如 deepseek [default: deepseek]
      --config <CONFIG>         配置文件。默认 ~/.config/qcode/config.toml
      --service <SERVICE>       钥匙串里的服务名 [default: qcode]
      --account <ACCOUNT>       服务里的账户名
      --approval-policy <PATH>  审批策略文件（[[rules]]）。会替换配置文件里的审批规则
  -h, --help                    打印帮助
