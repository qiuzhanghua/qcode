List stored sessions, newest first

Usage: qc sessions list [OPTIONS]

Options:
      --data-dir <DATA_DIR>
          Data directory. Defaults to the XDG data home

      --titles
          Also print the title the sidebar shows for each session.
          
          Reading a title means scanning the session log (the last rename wins), so this is opt-in: a plain listing stays index-only.

      --config <CONFIG>
          Config file. Defaults to ~/.config/qcode/config.toml

      --approval-policy <PATH>
          Approval policy file ([[rules]]). Replaces the config's approval rules

  -h, --help
          Print help (see a summary with '-h')
