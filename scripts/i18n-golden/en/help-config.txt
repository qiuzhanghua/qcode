Show or edit the config file

Usage: qc config [OPTIONS] <COMMAND>

Commands:
  show     Print the effective (merged) configuration
  edit     Open the user config in $EDITOR
  migrate  Rewrite a v1 file into the schema-2 shape (ADR-0065): fold `[providers.*].default_model` into `[default-model]`, collapse model tables that only carry an id, and switch `version` to `schema`
  key      Store an API key in the platform key store (ADR-0039)
  init     Generate a config file from a built-in template (ADR-0104)
  help     Print this message or the help of the given subcommand(s)

Options:
      --data-dir <DATA_DIR>     Data directory. Defaults to the XDG data home
      --config <CONFIG>         Config file. Defaults to ~/.config/qcode/config.toml
      --approval-policy <PATH>  Approval policy file ([[rules]]). Replaces the config's approval rules
  -h, --help                    Print help
